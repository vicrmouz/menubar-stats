# MenuBarStats
<!-- impeccable:product-schema 1 -->

## Platform
Native desktop: macOS and Windows 10/11.

## Stack
SwiftUI for existing macOS app; C#/.NET 8/WPF for Windows, approved in the Windows spec and plan.

## Purpose
Show machine health and Claude/Codex plan usage together for people programming with AI agents. Windows adds a taskbar overlay with CPU/RAM and a click-to-open panel.

## Constraints
The user requires the aesthetic of the existing macOS version. Preserve Portuguese labels, compact layout, system/Claude/Codex sections, local data sources and no telemetry. Windows overlay does not reserve Explorer space. Windows-only visual verification remains required.
